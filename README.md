\# Smart E-Learning Management System



\## Project Description



Smart E-Learning Management System is a Java-based application developed using Object-Oriented Programming concepts to manage student information and academic activities efficiently.



The system allows administrators to add students, manage attendance, update marks, generate report cards, search course information, and save student data permanently using file handling.



\## Features



\- User Login Authentication

\- Add Student

\- Display Student Information

\- Update Attendance

\- Update Marks

\- GPA Calculation

\- Generate Report Card

\- Search by Course

\- File Handling

\- Automatic Data Loading



\## Technologies Used



\- Java

\- OOP

\- Collections Framework

\- File Handling

\- Exception Handling



\## OOP Concepts Used



\- Encapsulation

\- Inheritance

\- Polymorphism

\- Constructor Overloading

\- Method Overriding
